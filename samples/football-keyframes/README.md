# Reframe Guard 足球关键帧样本

共 30 张 JPEG，均为源视频解码得到的 1280×720 原比例画面。两场比赛各 15 张，每场远景、特写、回放各 5 张。未添加栅格、标签或额外水印；保留源转播的比分牌与水印。

## 查看

- `index.html`：本地图片浏览页，点击缩略图打开原图。
- `frames/`：30 张原始抽帧图片。
- `previews/contact-sheet.jpg`：全部图片总览。
- `previews/wide.jpg` / `closeup.jpg` / `replay.jpg`：分类总览。
- `manifest.csv` / `manifest.json`：每帧的来源、时间戳、分类、说明、尺寸、SHA-256。
- `metadata/`：不含临时媒体下载地址的公开来源元数据。

## 抽取与分类

通过 yt-dlp 获取官方完整转播源的 720p 视频轨道（format 136），使用 FFmpeg 精确 seek 解码单帧。先抽取候选画面，再根据图片及相邻时刻目视筛选，排除明显转场叠化。抽帧阶段未下载完整比赛文件；现已另外保存完整比赛视频，见下方。

`category` 为互斥的取样分组：`wide` 远景、`closeup` 特写、`replay` 回放。回放本身也可能是远景，具体景别另见 `shot_scale`。特写涵盖球员、教练及球迷。回放根据进球前后顺序、重复动作和机位变化综合判定，不能仅凭单张图片必然识别。

标签来源为助手目视检查（`assistant_visual_review_with_temporal_context`），尚未经过人工独立复核。此包是静态关键帧候选集，不含裁切框或逐帧跟踪真值，不能单独用于验证连续裁切的平滑程度。
